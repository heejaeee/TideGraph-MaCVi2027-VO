Monocular maritime visual odometry using video, timestamps and calibration. Frozen VGGT Omega with 16 frame windows and 8 frame overlap uses input resolution 512 for FLIR visible and 416 for wide clips. FLIR uses an all pairs robust yaw graph, 2 second Gaussian smoothing and rotation gains 1.20 for six clips with higher land visibility and 1.10 for the remaining five. Groups are fixed by pretrained semantic masks without test ground truth. Wide clips retain TV10 water flow speed. Infrared retains the previous pretrained rotation and KLT fusion. External pretrained weights are used. Global settings were selected using development and leaderboard feedback.
